# My New Language

My New Language is a simple programming language designed for educational purposes. It allows users to perform basic printing tasks using the `show` function.

## Features

- **Lexer**: Tokenizes the input source code and identifies syntax elements, including the `show` function.
- **Parser**: Processes tokens generated by the lexer and constructs an abstract syntax tree (AST) for the `show` function.
- **Code Generation**: Translates the AST into LLVM intermediate representation (IR) to produce output.
- **Testing**: Includes test cases to verify the functionality of the `show` function.

## Getting Started

### Prerequisites

- CMake
- Clang
- LLVM

### Building the Project

1. Clone the repository:
   ```
   git clone <repository-url>
   cd my-new-lang
   ```

2. Create a build directory:
   ```
   mkdir build
   cd build
   ```

3. Run CMake to configure the project:
   ```
   cmake ..
   ```

4. Build the project:
   ```
   make
   ```

### Usage

To use the `show` function, create a file with the `.lang` extension and write your code as follows:

```
show `Hello, World!`;
```

Then, run the compiler on your source file to produce the output.

### Running Tests

To run the tests for the `show` function, execute the following command in the build directory:

```
make test
```
