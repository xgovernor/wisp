# Overview

**Wisp** is a C-based, strongly-typed programming language with a simple, readable syntax, template string interpolation, and user-friendly CLI. It is built using Clang/LLVM and designed for easy extension and robust error handling.

## Goals

- Simple, readable syntax for beginners and advanced users.
- Strong typing and explicit variable declarations.
- Easy string interpolation and printing.
- Clear error messages and runtime statistics.
- Extensible architecture for new features.

## Features

- Strongly typed variables and constants
- Template string interpolation
- Simple print statement (`show`)
- C-style comments
- CLI flags for info and stats
- Robust error handling
